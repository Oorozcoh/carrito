# src/public/

Los archivos estáticos reales (CSS, JS del cliente) se sirven desde
`/public` en la raíz del proyecto (ver `express.static` en
`src/app.js`). Esta carpeta se mantiene vacía por consistencia con la
arquitectura de referencia del curso, para no duplicar esos assets ni
crear una segunda fuente de la verdad para archivos estáticos.
